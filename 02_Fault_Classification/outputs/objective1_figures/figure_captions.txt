FIGURE CAPTIONS — Objective 1 group-disjoint results
======================================================================

Figure 1. Consolidated Objective 1 results.
Pooled out-of-fold five-class Macro F1 for ten feature configurations across four model families, split into string-level electrical / sensor-availability configurations (left) and aggregate-signal / reduced-feature representations (right). Protocol: group-disjoint 5-fold cross-validation over all 16 reconstructed recording days; every row receives exactly one out-of-fold prediction. Uncertainty is the fold standard deviation (ddof=1, n=5). Error bars show fold SD. Every configuration in the right-hand section still requires both string voltage and both string current sensors, because p_dc_computed = vdc1×idc1 + vdc2×idc2; NO_CURRENT and NO_VOLTAGE are the only genuine hardware-removal ablations. MLP used balanced training-fold downsampling because scikit-learn 1.5.2 MLPClassifier supports neither class_weight nor sample_weight, whereas LogReg, RF and HistGBM used class weighting. Cross-model differences therefore combine classifier family with imbalance strategy and are not a controlled comparison of architecture.

Figure 2. Sensor-removal penalty across model families.
Paired within-fold Macro F1 reduction when current sensing or voltage sensing is removed from the full string-level electrical set, for each model family. Points are means of the five paired within-fold differences; error bars are their SD (ddof=1, n=5). Protocol: group-disjoint 5-fold cross-validation over all 16 reconstructed recording days; every row receives exactly one out-of-fold prediction. Uncertainty is the fold standard deviation (ddof=1, n=5). Voltage removal cost more than current removal in 20 of 20 paired model × fold comparisons. MLP used balanced training-fold downsampling because scikit-learn 1.5.2 MLPClassifier supports neither class_weight nor sample_weight, whereas LogReg, RF and HistGBM used class weighting. Cross-model differences therefore combine classifier family with imbalance strategy and are not a controlled comparison of architecture.

Figure 3. Split-induced optimism.
The same data, features, model and fold count evaluated under two partitioning rules. The stratified random-row arm is a DIAGNOSTIC ONLY: it is methodologically invalid for reporting results, because adjacent seconds of the same physical fault event appear in different folds, and it must not be read as a result. Random-row folding raises the score and collapses fold SD from ±0.043–0.050 to ±0.001–0.002, manufacturing an appearance of precision. Uncertainty is fold SD (ddof=1, n=5).

Figure 4. Pooled out-of-fold confusion matrix, best configuration (Electrical + irradiance, MLP).
Row-normalised (recall orientation); each cell shows the normalised value and the raw count. Pooled across all five group-disjoint folds, so every row of the dataset is counted exactly once. Protocol: group-disjoint 5-fold cross-validation over all 16 reconstructed recording days; every row receives exactly one out-of-fold prediction. Uncertainty is the fold standard deviation (ddof=1, n=5). Pooled Macro F1 for this configuration is 0.986 ± 0.008.

Figure 6. Degradation recall by event character.
Recall for degradation-labelled samples, split between the standard ~600-sample scheduled inductions and the two long anomalous events (1,779 and 2,695 samples, recording groups 8 and 9). Each model uses its best configuration (LogReg: Electrical + irradiance; RF: Electrical + irradiance; HistGBM: Electrical + irradiance; MLP: Electrical + irradiance). Protocol: group-disjoint 5-fold cross-validation over all 16 reconstructed recording days; every row receives exactly one out-of-fold prediction. Uncertainty is the fold standard deviation (ddof=1, n=5). The event-character split is a diagnostic breakdown: no sample was removed or relabelled.
